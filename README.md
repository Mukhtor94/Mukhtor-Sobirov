# Mukhtor-Sobirov
Optosky–Sentinel-2B Wheat Spectral Comparison

This repository provides the Python computational notebook and input data associated with the manuscript:

Cross-sensor agreement between field spectroscopy and Sentinel-2 vegetation indices over wheat fields: Spectral response harmonisation and point–pixel concordance assessment.

Repository contents

Supplementary_Code_Optosky_Sentinel2.ipynb — Python notebook for spectral processing and inter-sensor statistical analysis.

BOKA_COLAB_INPUTS_ONLY.zip — input data archive used by the notebook.

Study information

Study area: Buka District, Tashkent Region, Uzbekistan.

Field measurements: 12 April 2026.

Satellite imagery: Sentinel-2B, 13 April 2026.

Vegetation indices: NDVI, GNDVI, and NDRE.

Reproducibility

The notebook and input archive are provided to support independent examination and reproduction of the computational workflow. Users should verify the required Python dependencies and input file paths before running the notebook.
